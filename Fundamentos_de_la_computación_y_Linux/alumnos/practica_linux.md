# Ejercicios Fundamentos Linux

## Ejercicio 1: Disecciona un comando
Explica cada una de las partes de este comando. 

$ grep -in "ERROR" logs/pipeline.log

Señala:
comando · opciones · patrón · archivo
Explica:
¿Qué cambia sin -i? ¿Y sin -n?

Con "i" ignora las mayúsculas y minúsculas y la n los numera.
